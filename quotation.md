# Quotation: Boss Reminisce — Artist Website

## Project Summary

A custom-designed, single-page artist portfolio website featuring:

- Bespoke visual identity and brand-aligned design system
- Custom audio player with swipeable card deck UI
- Responsive bento grid photo/video archive
- Scroll-driven animations (GSAP + ScrollTrigger)
- Physics-based smooth scrolling (Lenis)
- Video autoplay on scroll
- Upcoming events timeline
- Mobile-first responsive design with separate mobile layouts
- Accessibility compliance (keyboard nav, ARIA, reduced motion)
- Performance-optimised static build (Astro)
- Custom typography system (Satoshi, fluid clamp-based)

## What Justifies This Pricing

This is not a template or a WordPress theme. The scope includes:

1. **Custom interaction design** — the card deck swipe, waveform player, and scroll-linked timeline are bespoke components, not plugins
2. **Animation engineering** — GSAP scroll reveals with custom easing, parallax, clip-path transitions, staggered entrances, all respecting accessibility preferences
3. **Performance discipline** — hand-written CSS (no framework bloat), static output, optimised asset pipeline, CLS prevention
4. **Dual mobile layouts** — not just "responsive" but entirely different layout strategies for mobile (staggered archive vs bento grid)
5. **Audio system** — custom player with waveform visualisation, keyboard controls, and event-driven track switching tied to the card deck
6. **Accessibility-first** — full keyboard navigation, ARIA labels, reduced motion handling built in from the start
